# 미국증시 모니터링 — 사용 참고서

거시·유동성·온체인 지표를 **방향성 참고용**으로 읽는 법을 정리한 문서입니다.
모든 추정·예측 지표는 투자 결정이 아닌 참고용이며, 최종 판단·책임은 사용자에게 있습니다.

## 개인 브리핑 API (Phase C)

개인 보유정보와 수집 결과는 `/api/personal/v1` 아래 별도 계약으로 관리합니다.
운영 서버에는 `PERSONAL_SESSION_SECRET`을 설정하세요. 모바일 앱은 설치마다
기기별 세션 토큰을 발급받으며, APK에는 `PERSONAL_API_TOKEN`이나 Supabase 키를
넣지 않습니다. `PERSONAL_API_TOKEN`은 서버 작업자용으로만 사용할 수 있습니다.
로컬 테스트는
`PERSONAL_API_ALLOW_LOCAL=true`와 `X-Owner-Id`를 함께 사용할 수 있습니다.

`PERSONAL_STORE_PATH`는 기본적으로 `data/personal-store.json`입니다. 이 파일은
가벼운 개발용 영구 저장소이며, 운영에서는 반드시 영구 디스크 또는 관리형 DB
볼륨으로 지정해야 합니다. Python 수집 작업자는 내부 런타임 비밀값으로 스냅샷을
저장하고, 모바일 앱은 저장된 읽기 모델만 조회합니다. 시세·뉴스·SEC의 원천별
성공 여부와 기준시각이 응답에 포함되며 부분 실패 상태에서는 전체 수익률을 확정하지
않습니다. 자세한 경로와 필드는 `API_CONTRACT.md`를 참조하세요.

> 💡 **공통 색상 규칙**: 🟢 안정(ok) / 🟡 경계(warn) / 🔴 위험(danger).
> 각 카드의 "※ 더미 데이터" 문구가 보이면 그 항목만 실데이터 연결 실패(새로고침 시 복구).

## 🧭 큰 그림 — 이 앱을 보는 순서

거시 환경은 **유동성 → 금리 → 실물경제 → 위험선호** 순으로 연결됩니다. 추천 읽기 순서:

1. **유동성&시장** 탭에서 *지금 시장이 평온한가, 스트레스 상태인가* (VIX/MOVE)
2. **The Plumbing**(상단 💧)에서 *유동성이 늘고 있나 줄고 있나* (순유동성)
3. **실물경제** 탭에서 *경기·물가·고용이 식고 있나 과열인가*
4. **글로벌/온체인**에서 *위험선호가 켜졌나 꺼졌나* (달러·스테이블·BTC ETF)
5. **뉴스/캘린더**로 *오늘의 이벤트와 헤드라인* 점검

## 1️⃣ 유동성 & 시장 탭

### 금융 배관 (VIX·MOVE 게이지)
시장의 "공포 온도계". 두 게이지가 동시에 빨개지면 리스크오프 신호.

| 지표 | 의미 | 🟢 안정 | 🟡 경계 | 🔴 위험 |
|---|---|---|---|---|
| **VIX** | 주식 변동성 | < 20 | 20~30 | 30+ |
| **MOVE** | 채권 변동성 | < 110 | 110~150 | 150+ |

- **Z-Score(60일)**: 현재 값이 최근 평균 대비 몇 σ 떨어져 있나. **±1.5σ 경고 / ±2.0σ 위험** — 절대 레벨이 낮아도 Z가 튀면 "갑작스러운 변화"를 의미.
- **Guardrail 판정**: VIX·MOVE·Z를 종합한 한 줄 결론. 🔴면 방어적으로.
- **구간별 압력(아코디언)**: 펼치면 세부 압력 원인. 평소엔 접어두고 경고 시 확인.

### Capital Migration (자본 대피)
- **현금 대피 압력(0~10)**: 높을수록 안전자산으로 돈이 도망치는 중. 7+ 주의.
- **HIGH VOLATILITY MODE 배너**: 뜨면 시장이 패닉 국면 — 신규 진입 신중.

### Institutional Fund Velocity (기관 자금 속도)
11개 SPDR 섹터 ETF의 **다이버전스 4구간**:

| 구간 | 의미 | 해석 |
|---|---|---|
| 🟢 **매집** | 가격↓ 자금↑ | 스마트머니가 저가 매수 중 (바닥 신호 가능) |
| 🟡 **분배** | 가격↑ 자금↓ | 고점에서 물량 떠넘기는 중 (천장 경계) |
| 🟢 **모멘텀** | 가격↑ 자금↑ | 건강한 상승 추세 |
| 🔴 **투매** | 가격↓ 자금↓ | 투매 국면 (바닥 근처일 수도, 추세 이탈일 수도) |

- **TQQQ/SQQQ 비율**: 3배 레버리지 롱/숏 비율. 높으면 투자자들이 공격적(과열 신호일 수 있음).
- **UVXY 헤지 수요**: 변동성 ETF 수요 — 높으면 시장이 보험을 사는 중(불안).
- 각 지표의 **해석/한계 토글**을 펼치면 주의사항이 나옵니다.

### Liquidity Flow (유동성 흐름) — 가장 중요
- **Net Liquidity Momentum (NLM)**: 시중 유동성의 가속도. 상승 = 위험자산에 우호적.
- **NLM vs S&P500 크로스오버**: 유동성과 주가가 벌어지면(괴리) 되돌림 가능성. 유동성이 먼저 꺾이면 주가 조정 선행 신호로 봄.
- **1~4주 예측**: 시뮬레이션 (confidence: high→low). **방향성만 참고**.
- **MMF/예금 4국면**:
  - 🔴 **뱅크런**(MMF↑·예금↓): 예금에서 머니마켓펀드로 도피 — 은행 스트레스
  - **중립** / **금리인하 기대** / **위험선호(riskon)**
- **레포 국면(ΔRRP × ΔSOFR Vol 4분면)**:
  - 🟢 정상유입 / 🔴 **역류경보**(RRP↑ & SOFR 변동성↑ = 단기자금 압박) / 독립 / 동반수축

### Interest Rates (금리)
- **2Y/5Y/10Y/30Y 오버레이**: 범례 클릭으로 개별 선 On/Off, 기간 토글.
- **스프레드 카드**:
  - **2s10s** (10년−2년), **3m10y** (10년−3개월)
  - **음수(역전) = 🔴 경고**: 역사적으로 침체 선행 신호. 다시 양수로 돌아설 때(정상화)가 오히려 침체 임박 구간인 경우가 많음 — 함께 봐야 함.
- **스티프닝/플래트닝**: 커브가 가팔라지나(경기회복·인플레 기대) 평탄해지나(둔화 우려).

## 2️⃣ 실물경제 탭

### 원자재 모멘텀 (12개)
원유·금·구리·천연가스 등. **구리·원유 상승 = 경기 확장 신호**, 금 상승 = 안전선호/인플레 헤지. 모멘텀(추세 강도)로 정렬해 무엇이 주도하는지 파악.

### 인플레이션 히트맵
PPI / CPI / Core CPI / PCE / Core PCE / 임금(YoY)을 색 그리드로:

| 색 | 의미 |
|---|---|
| 🟢 **Cooling** | 둔화 중 (디스인플레이션) |
| 🔴 **Heating** | 가속 중 (인플레 재점화) |
| 🟡 **Sticky** | 끈적임 (안 떨어짐) |

→ Core PCE는 연준이 가장 중시하는 지표. 여기가 🔴면 금리인하 지연 가능성.

### 기대 인플레이션
- **BEI(손익분기 인플레)·5Y5Y·미시간대 서베이** 교차 점검. 시장 기대가 닻 내려져 있나(anchored), 풀리고 있나.

### Corporate Pulse (기업 맥박)
- **GDPNow**: 애틀랜타 연준 실시간 GDP 추정.
- **지역 연준 제조/서비스 복합평균**: >0 확장 / ~0 / <0 수축.
- **ISM 원본**은 외부 링크 버튼으로.

### Labor Pipeline (고용 도미노 5단계)
고용 악화는 **순서대로** 전이됩니다. 앞 단계가 무너지면 뒤가 따라옴:

`S1 JOLTS(구인) → S2 임시직 → S3 신규 실업수당 → S4 NFP(고용) → S5 샴룰`

- **서킷브레이커**: 앞 단계가 경고면 도미노 진행 중.
- **🚨 샴룰 0.50 돌파 = 침체 신호 발동** (실업률 상승 모멘텀). 푸시 알림 대상.

### Consumer Health (소비 3단계)
- 심리 → 저축률/연체율 → 실질 핵심 소매판매.
- **🎭 가짜 호황 경고**: *심리는 양호한데 저축률·연체율이 동시에 악화*되면 표시. 겉으론 소비가 버티지만 속은 빚으로 지탱 — 가장 조심할 신호.

## 3️⃣ 글로벌 탭

이종자산 상관관계로 위험선호를 읽습니다. **당일 노이즈는 이동평균(10DMA)으로 제거**, 3영업일 전과 비교해 휩쏘를 걸러냅니다.

- **DXY vs Broad Dollar (4국면 음영)**: 달러 강세/약세 국면. **달러 강세 = 위험자산엔 역풍**(신흥국·원자재·주식 압박). SPY 오버레이 토글로 주가와 비교.
- **글로벌 팩토리 (AUD/USD + KOSPI)**: 호주달러·코스피는 글로벌 제조업/무역의 풍향계. 동반 하락이면 글로벌 수요 둔화.
- **글로벌 수요 (EUR/USD + FEZ)**: 유로·유럽 ETF로 유럽 수요 점검.

## 4️⃣ 온체인 탭

### 스테이블코인 (온체인 달러 배관)
- **USDT+USDC 총 시총**: 온체인 달러 유동성의 프록시. 늘면 크립토에 자금 유입.
- **USDC 점유율(±1.5p 동적 밴드)**: 규제친화 자금(USDC) vs 역외 수요(USDT)의 무게중심 변화.

### RWA (실물자산 토큰화)
- DefiLlama 기준 상위 10개 프로토콜 + **토큰화 국채(T-Bill)** 비중 + 2년 추이. 전통 금융 자금이 온체인으로 들어오는 정도.

### BTC 현물 ETF (기관 수요)
- **누적 순유입** + 일별 플로우.
- **신고점 대비 색상**: 🟢 95%+ / 🟡 85~95% / 🔴 85%↓ (기관 매수세 강도).
- **🩸 3일 연속 순유출 = 경고 배너 + 푸시**: 월가 매수세 둔화 신호.

## 🛠️ 전용 화면 (상단 아이콘)

### 📅 국채경매 분석
월간 캘린더에 입찰 유형별 5색 점:
- 🟢 **Bill**(단기) / 🔵 **Note**(중기) / 🟣 **Bond**(장기) / 🟡 **TIPS**(물가연동) / 🟦 **FRN**(변동)
- 날짜 클릭 → 발행액·**응찰배수**(2.2 미만이면 수요 약함 🟡)·낙찰금리.
- 장기물(Bond) 발행 급증 = 시장에 듀레이션 공급 부담 → 금리 상승 압력.

### 💧 The Plumbing (유동성 배관 예측)
- **연준 상태(WALCL)**: 4주 변화로 **QT(긴축)/QE(완화)/중립** 판정. QT = 유동성 흡수.
- **TGA 감시(WTREGEN)**: 재무부 계정. **TGA↑ = 시중 현금 흡수(드레인) 🔴**, TGA↓ = 방출.
- **순유동성 = WALCL − TGA − RRP**: 이게 늘면 위험자산 우호적.
- **4주 드레인 예측**: 추세 외삽 시나리오. **투자 결정 아닌 방향성 참고용**.
- **QRA 수동 수정**: 분기 자금조달계획(대상분기/순차입목표/TGA말잔목표/발표일)을 직접 입력하면 예측에 반영. 재무부 발표 후 업데이트하면 정확도↑.

## 📌 종합 시나리오 예시

**"리스크오프(방어) 신호가 겹칠 때"** — 아래가 동시에 나타나면 강한 경계:
- VIX 30+ & MOVE 150+ (🔴🔴)
- 순유동성(NLM) 하락 전환 + 레포 역류경보
- 2s10s 역전 해소(정상화 시작) + 샴룰 상승
- BTC ETF 3일 순유출 + 달러 강세 국면

**"리스크온(우호) 신호가 겹칠 때"**:
- VIX < 20, 순유동성 상승, 섹터 "매집/모멘텀", 스테이블 시총 증가, 달러 약세.

> 한 지표만 보지 말고 **유동성·금리·실물·위험선호를 교차 확인**하세요. 그것이 이 앱의 설계 의도입니다.
